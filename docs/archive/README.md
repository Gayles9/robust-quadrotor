to understand the project now. Dates and source identities inside records are
experimental provenance and remain intact.

Record filenames use stable descriptions. Their dates, numerical claims and
literal command transcripts still describe the original work. Markdown links
resolve to retained files; historical command paths have not been rewritten as
if those commands were run in today's layout.

The [feedback co-design record](../progress/2026-09-24-feedback-codesign.md)
remains at its original path because an experiment authenticates its bytes.
Frozen [design decisions](../decisions/README.md) also retain their established
paths. These are reproducibility inputs, not the primary reading path.
